SECTION 11 — TECH STACK

11.1 Guiding Principles

Performance-first — content pages must be near-instant (Core Web Vitals)
Scalable from Day 1 — architecture should not need a rewrite at 100k users
AI-ready — automation layer added without major refactor
Lean infrastructure — minimize ops overhead for a small team

11.2 Recommended Stack

FRONTEND
Framework: Astro (confirmed)
Why: Best-in-class for content-heavy + SEO-critical sites. Island architecture means static-by-default with dynamic where needed. Perfect for airport guides + tools hybrid.
Rendering: SSG for all content/blog pages. SSR (Astro server endpoints) for dynamic tools (deal analyzer, trip engine).
Styling: Tailwind CSS (pairs naturally with Astro, fast to build)
UI Components: Shadcn/ui or Radix UI (accessible, unstyled, composable)

BACKEND / DATABASE
Database: Convex (confirmed)
Why: Real-time by default, serverless functions built in, generous free tier, excellent DX. Perfect for: saved trip plans, user airport profile, alert preferences, waitlist data.
Auth: Clerk — native Convex integration, handles social login + email, free tier sufficient for launch
File storage: Convex built-in or Cloudflare R2 (if needed for generated reports/PDFs)

EMAIL
Provider: Resend + React Email
Why: Modern, developer-friendly, deliverability is excellent, generous free tier. Write email templates as React components.

ANALYTICS + EVENTS
Analytics: PostHog (self-hosted or cloud)
Why: Tracks funnels, events, session replay, feature flags — all in one. Critical for understanding which tools convert.
Also: Simple UTM tracking through all affiliate links

AUTOMATION / WORKFLOWS
Tool: n8n (self-hosted on a small VPS, or n8n cloud)
Why: Visual workflow builder, connects to any API, ideal for:
  - Award alert workflows
  - Deal scraping pipelines
  - Email trigger sequences
  - Affiliate link performance tracking
Alternative if simpler needed: Make.com (less control, easier to start)

AI LAYER
SDK: Vercel AI SDK (works with Astro SSR)
Models: OpenAI GPT-4o for dream trip engine reasoning / Claude for long-form generation
Later: Fine-tuned model on Texas award data

HOSTING / CDN
Host: Cloudflare Pages (free tier, global CDN, zero cold starts for static)
Functions: Cloudflare Workers for edge logic or Convex actions
Domain + DNS: Cloudflare

PAYMENTS (Phase 2)
Provider: Stripe
Use: Membership tier, premium reports

AFFILIATE TRACKING
Built-in: UTM parameters on all outbound card links
Later: Impact.com or PartnerStack if affiliate network grows

11.3 Architecture Diagram (Text)

User Browser
  → Cloudflare CDN (static pages, instant)
  → Astro SSR (dynamic tools, trip engine, deal analyzer)
    → Convex (user data, saved plans, alerts)
    → Clerk (auth)
    → AI API (OpenAI/Claude for plan generation)
    → n8n (background automation: alerts, scrapers, email triggers)
    → Resend (transactional + marketing email)

11.4 Why This Stack Scales

Static content pages (airport guides, blog): served from CDN edge — handles millions of requests, zero cost increase
Dynamic tools: Convex scales automatically, serverless
Database: Convex handles real-time reactivity natively (live deal alerts, saved plan updates)
Automation: n8n runs independently — can add scrapers, alert pipelines, AI workflows without touching the main app

11.5 Build Order Recommendation

Phase 0 (Waitlist): Astro static page + Convex for email capture + Clerk for future auth
Phase 1 (MVP): Astro content site + airport guides + Convex user profiles + basic tools
Phase 2: n8n automation + Resend email flows + AI trip engine
Phase 3: PostHog optimization + Stripe membership + mobile (Expo + same Convex backend)
